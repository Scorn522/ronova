## Runtime failure addressed

The alpha.7.10 Forge run proved that Native Root loading, snapshot publication,
judgment, lineage rejection and save/re-entry worked, but it also exposed four
release blockers:

- client Presence/Authority reads submitted epoch `0:0` to an active integrated Root;
- entity query and Admission paths crossed JNI per object and per boundary;
- a no-op state command could reach the publication lane;
- returning `null` from `EntityType.create(Level)` made `NaturalSpawner` log one
  warning for every intentionally suppressed spawn.

## Repaired boundary

```text
Root commit / reconcile
  -> Native snapshot acceptance
  -> immutable ProjectionBundle
       -> AuthorityTopologyProjection (local read)
       -> AdmissionProjection (local indexed read)
       -> PresenceProjection (local read)

Explicit Judgment
  -> Native decision
  -> Root commit
```

Authority, Admission and Presence can no longer call `LocalDominionCore`.
`JudgmentExecutor` remains the only gameplay decision caller. JNI remains for
snapshot publication, coordination, recovery and explicit judgment rather than
routine entity reads.

Natural spawn objects are observed at the factory boundary and silently denied
at JOIN, `ServerLevel`, persistent-manager or first-tick boundaries. Those
rejections still increment Admission counters, but the factory never returns
the intentional `null` that caused the warning storm.

No-op Root receipts are compared with the current projection and returned
without publication. A same-epoch content mismatch fails closed.
