### 兼容档默认关闭的五项

直接清除、重建压制、代码防御剥离、调用链攻击、全返回。其他九项请求 Compatible 深度。高级图仍为 r53 的 12 MONITOR / 42 PROTECT_RONOVA。

`strongAttack` 只描述编排许可，单独开启不能授权改血、移除或全返回；组合动作含多个效果时每项许可都必须满足。具体字节码、第三方 HUD 等分支还必须传入额外高级依赖，后续 executor 注册需要审核这份声明，不能由调用者随意省略。

## 2. 本批实际生产接线范围

| 普通项 | 已接线 | 尚未完成 |
|---|---|---|
| terminalize | Root 拒绝关闭后的新 CommitJudgment/非空 batch，保持旧 receipt 重放有效 | 无持久终结的独立改血攻击路径 |
| 其余十三项 | 保存、迁移、解析、命令编辑已接线；尚不能控制旧终态链的独立物理分支 | 专属生产 executor、独立效果证明与完整 GUI 尚未接入 |

本批保留 r53 的 TerminalLifecycle 物理链，不把同一旧分支冒充三档实际强度。`permitsBaselineAction` 仅接受 terminalize，用于新 Root 提交；其余动作必须经过带能力/证据的解析与后续 executor 契约。

这是有意保留的分批边界：旧链会先执行隔离/Admission，单独屏蔽 remove 可能留下不可见且不能正常 tick 的未清理对象。改血、直接清除、记录清理要与隔离/追踪和完成合同一起解耦。本批没有把这些未完成开关接到运行中，不能用 `directClear off` 宣称保留死亡动画，也不能用 `rewriteLife off` 宣称已经禁止旧终态链改血。

关闭普通项**不删除已有 Tombstone，不重新许可旧资格**。已有准入拒绝、隔离与恢复义务仍由已提交 Truth 驱动；本批不借配置关闭解除裁决。关闭终结后，当前持久攻击链会拒绝新终结，不自动切换为尚未实现的独立改血链。

`CommittedJudgmentGate` 一批建一次索引，逐目标 O(1) membership 检查。它是控制流/回执归属约束，**不是同 JVM 内不可伪造的安全边界，也不是 exactly-once effect 或 CLEARED 证明**；副作用未知恢复、TargetEpoch 全链租约与物理身份再验证仍待实现。

## 3. 命令

```text
/ronova strength status
/ronova strength compatible
/ronova strength enhanced
/ronova strength extreme
/ronova strength custom
/ronova strength attack allReturn off
/ronova strength attack rewriteLife enhanced
/ronova strength attack directClear extreme
/ronova strength option attack.dispatch strict_all
```

编辑权限沿用 OP level 2。普通值：`off / compatible / enhanced / extreme`；高级值：`off / monitor / protect_ronova / related_paths / strict_all`。来源追踪用 `option attack.source_trace ...`。命令补全包含全部 14 项/54 键，跟随预设通过重新选择整套 preset 恢复。

状态输出区分保存值、当前请求与高级执行检查；当前缺真实 executor/evidence 的项仍 UNAVAILABLE，不得视为全返回已生效。五页 GUI 和客户端策略同步协议本批未做；协议仍为 9。
