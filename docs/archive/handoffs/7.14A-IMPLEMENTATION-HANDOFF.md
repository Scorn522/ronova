## Implemented

- Per-server `RawObservationSource` and weak `TopologyGraph` with immutable
  level/UUID/related snapshots and server ownership checks.
- Immutable one-time feature selection through
  `ronova.714a.rawObservation.enabled` or
  `RONOVA_714A_RAW_OBSERVATION_ENABLED`, defaulting to legacy/false.
- `shouldIndex` / `shouldJudge` separation；terminal filtering remains private to legacy topology.
- Runtime migration of construction, admission, repair, discovery, Judgment,
  terminal cleanup, identity clearing, telemetry, commands, action logs, and
  shutdown through the selected observation port.
- Enabled-mode D5 behavior: terminal enforcement cannot forget raw state;
  disabled mode retains the 7.13 `TopologyIndex.forget` rollback path.
- Per-server passive `TerminalWatchSet` mirror keyed by UUID and dimension,
  with O(1) aggregate metrics, UUID-scoped snapshots, active-entry retirement,
  a bounded 1,024-entry diagnostic history, stateless disabled implementation,
  release cleanup, and isolated notification-failure accounting.
- Read-only permission-2 `/ronova diagnose_uuid <uuid>` evidence command.
- All 32 standalone tests are registered. After removing the unused
  `shouldTrack` and `AuthorityGuard.bind` compatibility aliases, the boundary
  regression was aligned with the current `restore` / `grant` API。当前 Ronova 候选已在 2026-08-28 通过 `clean build` 的完整 32 项自检。
- Frozen 7.13 baseline run `20260813-004809-366Z` copied and hash-verified.
- Separate reobfuscated Forge validation fixture and a versioned
  prepare/capture/verify runner for all eight live scenarios plus performance.
- RAW smoke run `20260816-064118-799Z` completed a 300-second window with 5,983
  tick samples, zero dropped tick samples, zero notification failures, and no
  ERROR/FATAL/WARN/Exception entries in `latest.log`.
- Formal byte-identical-save performance runs `20260816-074145-245Z` (LEGACY)
  and `20260816-081437-881Z` (RAW) used matching `-Xmx7680m`, source hash, and
  6,000 tick samples. RAW changed p50/p95/p99 by
  -5.13%/-10.37%/-19.45%, passing the +5%/+5%/+10% gates.
